Demostración de microservicios

Cada botón usa un microservicio distinto, escrito en un lenguaje diferente, todos conectados a la misma base de datos en Supabase.

🟢 Python (Flask) — Lectura principal

Se usa automáticamente al entrar a Comentarios.

🟠 Java (Spring Boot) — Insertar, Actualizar, Eliminar

Seleccionable desde los formularios de agregar/editar/eliminar en Comentarios.

🟣 Node.js — Insertar, Actualizar, Eliminar

Seleccionable igual, desde el mismo lugar.

🔵 PHP — Insertar, Actualizar, Eliminar

Seleccionable igual, desde el mismo lugar.

🟢 Node.js (respaldo) — Resiliencia de lectura

Se activa automáticamente si el microservicio de Python falla al consultar comentarios.
